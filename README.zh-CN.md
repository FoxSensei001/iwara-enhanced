## 🌟 介绍

**Iwara Enhanced** 是一个为 iwara.tv 官方网站（以及它的 AI 站 iwara.ai）而设的社区用户脚本。它在保持原版页面完全可用的基础上，为内容创作者和浏览用户补充实用功能：更流畅的发布流程、更便利的内容管理和搜索体验。

> [!NOTE]
> 这是一个非官方社区项目，与 Iwara 官方无任何关联。

> [!IMPORTANT]
> **使用规则** — 请遵守 Iwara 的网站规则和内容政策。任何规则违反（如上传测试内容、未完成作品等）可能导致账户警告或限制。

> 下面的截图都是真实的 iwara.tv 页面，在同一份**虚构数据**上分别渲染「原站」和「装上脚本后」：标题、用户名、简介、标签、封面和头像都是占位内容。截图统一使用英文界面。

## ✨ 功能

### 🖊️ 创作工作台

把视频和图片的发布页、编辑页与内容管理页统一为一套分步流程。

<p align="center"><img src="docs/images/studio.png" alt="创作工作台" width="100%"></p>

- **四步发布流程**：上传 → 内容 → 标签 → 发布
  - 视频选中即开始上传，可边传边填表
  - 上传完成后存进草稿，刷新页面无需重新上传
- **所见即所得编辑**
  - Markdown 编辑支持（回车新段落、Shift+回车换行）
  - 支持 `@` 提及用户、引用自己的作品
  - `Tab` 键快速跳到下一个填空项
- **智能标签**
  - 多语言搜索：英文、简体中文、繁體中文、日本語
  - 视频和图库均需选一个类别
  - 选过的标签自动记录在「用过的标签」
  - 词库来自 [LoveIwara](https://github.com/FoxSensei001/LoveIwara/tree/master/tool/data/iwara_tags) 的 `tool/data/iwara_tags`，除英文外是机器翻译
- **灵活的封面管理**
  - 从服务端生成的候选帧中选择
  - 高级会员可上传自定义封面
- **发布模板**
  - 标题可包含 `{填空}` 占位符、`{#}` 自动递增期数
  - 任意步骤套用模板
  - 发布前后均可保存当前内容为新模板
- **内容管理面板**
  - 卡片式墙面，带封面缩略图
  - 支持搜索、排序、统计
  - 显示视频与图库各自的发布冷却状态

### 🏠 首页

<p align="center"><img src="docs/images/home.png" alt="首页" width="100%"></p>

- 站点公告收成紧凑的一行。
- 各分区（视频、图片等）可以原地切换 最新 / 热门 / 人气，并原地翻页。

### 🔍 搜索增强

<p align="center"><img src="docs/images/search.png" alt="高级搜索面板" width="100%"></p>

- 顶栏搜索框可先选择板块（视频、图库、帖子、用户等）再搜索。搜索结果页有自己的一整条搜索栏，这时顶栏的搜索框会收起。
- 搜索结果页上，关键词以输入框里现在的文字为准：删掉关键词后直接改筛选，也只按筛选条件搜。
- 高级面板支持多个标签（且 / 或）、排除标签、作者、精确短语、日期、评级和排序，并实时预览生成的搜索语句。

### 📄 分页

<p align="center"><img src="docs/images/pager.png" alt="分页栏" width="100%"></p>

- 列表页提供传统分页栏，可跳到任意页。
- 视频和图库列表还可切换为瀑布流（无限滚动），选择会被记住。

### 👤 用户标识

- 头像按身份显示光环：高级会员为渐变环并带柔和光晕，管理员红色，版主绿色，受限用户灰色。
- 用户资料页显示身份徽章。

### 💬 评论与帖子渲染

<p align="center"><img src="docs/images/forum.png" alt="论坛引用与小尾巴" width="100%"></p>

- 论坛引用渲染为带头像、昵称和「跳转到楼层」链接的引用条。
- 小尾巴显示为灰色小字脚注，站内表情按合适大小显示。
- 只改变显示效果，不改变消息的发送方式。

### 🏷️ 标签翻译与筛选

- 视频、图库等页面上的标签链接按当前语言显示（来自词库），鼠标悬停可看原文。
- 视频和图库列表可按多个标签筛选（且），候选来自最近用过的标签和当前列表中的标签。

### 📬 订阅页筛选

<p align="center"><img src="docs/images/subs.png" alt="订阅页筛选" width="100%"></p>

- 订阅页的视频、图像两栏右侧多出「筛选」和「标签」两张卡：排序（默认「最新」，另有趋势 / 人气 / 点赞 / 观看）、评级（默认全部）、发布年月，以及按标签过滤（且）；每张卡右上角可一键重置。
- 筛选只在关注的作者范围内生效，切换不刷新页面；视频和图像两栏共用同一套筛选。
- 常用的标签组合可以保存，视频、图库、订阅页通用。
- 视频、图库列表页右栏多一张「评级」卡（全部 / 全年龄 / 成人），不用去侧栏切全站评级；默认跟随侧栏设置。
- 窄屏上卡片默认收起，点标题展开。

### 🙋 作者页

<p align="center"><img src="docs/images/profile.png" alt="作者页" width="100%"></p>

- 横幅和头像可以点击放大查看原图（和图片详情页同一个看图器，两张之间可以左右切换）。
- 头部 @用户名下面显示粉丝数和关注数，点击进入对应列表；好友按钮的「待办」改成「已申请」。
- 「关于」页：简介放进卡片；「最新视频 / 最新图片」标题可点击，右侧有 最新 / 热门 / 人气 按钮直达对应排序，分区下面有分页条，可以原地翻页；评论标题显示条数。
- 视频、图片页右栏有「筛选」（排序、发布年月）、「翻页方式」（传统分页 / 瀑布流）和「标签」三张卡，和订阅页一样，切换不刷新页面。
- 右栏在宽屏上随页面滚动保持可见；关注中 / 粉丝页的用户显示为卡片。
- 翻页、切换视频 / 图片等栏目后，页面回到头像栏下面（列表开头），不再弹回页面顶端。
- 手机上横幅和头像缩小，入口改成一行可横向滑动的标签。

### 🃏 卡片预览

<p align="center"><img src="docs/images/cardpreview.png" alt="卡片预览" width="100%"></p>

- 视频、图库卡片的作者行最右边有一个「⋯」，点开是一张预览卡片，不用离开列表：大封面（视频会播放动图预览）、完整标题、作者、统计（R-18 / 私有 / 播放 / 点赞 / 评论 / 时长 / 张数 / 发布时间）、简介、标签（显示成你的语言）。
- 图库可以在卡片里左右翻页（滑动、触控板横扫、箭头键或悬停箭头），点某一张直接用大图查看器看。
- 底部一行：点赞、复制链接、新标签打开、打开。
- 宽屏是左封面右信息；手机上是从底部弹出的面板，往下拖可以关闭。

### ✅ 富文本编辑与规则确认

<p align="center"><img src="docs/images/comment.png" alt="评论编辑器与规则开关" width="100%"></p>

- 站点上所有写 Markdown 的输入框（评论、回复、论坛发帖、编辑）都换成和工作台同一套所见即所得编辑器，并按该输入框的上限显示「已输入 / 上限」。
- 发评论、回帖等表单里站点那一长行「规则 ☐ 按下提交按钮…即表示我同意…」收成提交键旁边的小开关「☐ 同意 规则」，记住你上次的选择（从没勾过就不勾）。
- 只在按下提交时才替站点勾上它自己的勾选框，打开页面不会让表单变成「已修改」，切页面、关标签不再被「确定离开吗」拦住。
- 没勾「同意」就按提交，会提示先勾选，不会悄悄失败。

### 🌐 翻译

- 评论、论坛帖子、动态、作者简介、首页公告，视频 / 图片的标题和简介，以及卡片预览弹窗，都有翻译按钮，放在各自的操作区里（「回复」旁、楼层号旁、「赞 / 分享」那一排、「简介」标题右侧、公告浮窗标题栏、预览弹窗底部那排按钮），用谷歌翻译译成站点当前的界面语言。
- 中外文混排的内容（比如一段英文加一段中文的公告）也有按钮，只翻译外语那几行。
- 翻译按钮是分段的：左边翻译 / 显示原文，右边箭头弹出语言菜单（15 种语言），选了就立刻把这一条译成该语言，并记住作为之后的默认；没选过时跟随界面语言。
- 译文直接替换原文，换行、链接、加粗、表情、行内代码都保留；再点一次显示原文。已经是界面语言、只有表情或链接的内容不显示按钮。
- 加载中、失败都显示在按钮上；结果在本次浏览中缓存。

### 🧭 侧边栏

- 语言、评级、主题变为侧边栏底部的图标开关；主题增加「跟随系统」。
- 论坛下新增子菜单，其中的「最近」列出所有板块的最新帖子。

## 📋 目标与边界

- 给网页端的普通用户和内容创作者带来便利：更顺手的发布、编辑和管理。
- 只服务于 iwara 官方网站，不接入任何外部站点的内容。
- 不做任何损害官方网站利益的功能，例如移除广告。

## 🛠️ 安装

打开 **[下载页](https://foxsensei001.github.io/iwara-enhanced/)**，它会按你的浏览器和设备推荐装法，并给出分步说明；页面上还能直接试用各项功能的演示。

推荐的两种装法都会自动更新：
- **油猴脚本**（电脑、手机都能用）：先装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)，再点 [安装脚本](https://foxsensei001.github.io/iwara-enhanced/iwara-enhanced.user.js)，在弹出的页面里确认安装。
- **Firefox 扩展**：正在提交 Firefox 附加组件商店，上架后下载页会给出安装按钮。

Chrome / Edge 也可以手动加载扩展，但不会自动更新，只会在有新版时提示，详见下载页。打包和发版的细节见 [extension/README.md](extension/README.md)。

装好后访问 iwara.tv 或 iwara.ai 即可生效。

**从旧版升级**：脚本名称和命名空间已更改，旧版用户请先卸载旧脚本，再安装本脚本，不要在旧脚本上直接覆盖更新。脚本现在在 `document-start` 阶段运行。

**使用提示**：创作工作台右上角的「⋯」菜单可以：
- 切回原版页面
- 重新查看功能引导

## ✅ 能做什么、不能做什么

**能做：**
- 只在 `iwara.tv` 和 `iwara.ai` 上运行（AI 站和主站是同一套前端、同一个接口），使用站点自身的登录状态和前端接口（上传、创建、编辑、删除、冷却、标签与用户推荐）
- 模板和草稿存储在站点的 `localStorage`（键以 `iwe:` 开头）
- 外部网络请求只有两类：从 jsDelivr 下载标签词库；点击翻译时，把你点击翻译的那段文字发送到谷歌翻译（`translate.googleapis.com`），不点击就不会发送
- 其余请求都只发往站点自己的 `api.iwara.tv`

**不能做：**
- 发布前的「我已阅读并同意网站规则」复选框需要由你自己勾选
- 无法绕过或修改站点的内容审核政策

## ⚠️ 已知限制

- 视频一旦保存了自定义封面，无法改回视频截帧，只能更换其它图片（服务端限制）
- 站点的详情接口有缓存：编辑保存后，其他用户可能需要等待一段时间才能看到更新；脚本会以保存结果为准，不会用旧值覆盖
- 上传限制、码率表、格式说明等内容会跟随站点发布页的更新而变化；站点改版后脚本可能需要更新
- iwara.tv 和 iwara.ai 的浏览器存储是分开的：设置、模板、草稿不会在两个站之间同步；模板可以用模板面板的导出 / 导入搬过去

## 👨‍💻 开发

```bash
npm install
node build.mjs
```

**项目结构：**
- 源码在 `src/`，按文件名顺序组装为 `dist/` 中的单文件脚本
- 编辑器采用开源 [Milkdown](https://milkdown.dev)（MIT License，基于 ProseMirror）
- 由 esbuild 将 `vendor/milkdown.js` 打包进同一个文件，安装时无需额外网络请求

**截图**：`docs/screenshots/capture.mjs` 在真实站点上分别渲染装 / 不装脚本的页面（英文界面、虚构数据），再排版成 `docs/images/` 里的图。运行方式见该文件开头的注释。
