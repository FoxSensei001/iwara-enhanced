会自动更新吗？Does it update itself?自動で更新されますか？
油猴脚本由脚本管理器定期检查更新，Firefox 版由 Firefox 自动更新，都不用管。只有 Chrome 手动加载的扩展需要你自己覆盖新版（有新版时它会提示）。Yes. The userscript is updated by your script manager, and the Firefox add-on by Firefox. Only the manually loaded Chrome extension needs you to unzip new versions over it (it tells you when one is out).はい。ユーザースクリプトはスクリプト管理が、Firefox 版は Firefox が自動で更新します。手動で読み込んだ Chrome 拡張機能だけは、新しい版を上書きする必要があります（出たときにお知らせします）。
为什么 Chrome 应用商店里没有？Why isn’t it on the Chrome Web Store?なぜ Chrome ウェブストアにないのですか？
